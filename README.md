# 팀 점심 정산

팀원들이 관리자 계좌에 미리 입금한 금액에서 각자의 식사비와 커피값을 차감하는 웹 장부입니다. 매장 식사와 배달을 구분하며 연간 무료 배달 혜택을 적용해 배달비는 따로 입력하지 않습니다.

## 화면 열기

| 화면 | 용도 |
| --- | --- |
| [개선판 체험](https://vvvis-ai.github.io/lunch-settlement/lunch_ledger_v2.html) | 예시 팀원으로 조회, 식사 기록, 입금 정정, 월말 검산 체험 |
| [운영 장부 조회](https://vvvis-ai.github.io/lunch-settlement/lunchmenu.html) | 팀의 공유 장부에서 입금·사용 내역과 잔액 조회 |
| [운영 장부 관리자](https://vvvis-ai.github.io/lunch-settlement/lunchmenu_admin.html) | 기존 Firebase 공유 장부 관리 |

## 개선판 사용법

1. **팀원 조회**에서 이름과 조회 월을 선택하면 전월 이월액, 이달 입금액, 사용액, 잔액이 표시됩니다. 거래를 펼치면 식사비와 커피값을 확인할 수 있습니다.
2. **관리자**를 처음 열 때 이 브라우저에서 사용할 비밀번호를 설정합니다. **오늘 식사 기록**에서 매장 또는 배달을 선택하고 참여자별 금액을 입력합니다. 커피는 마신 사람만 선택하며 저장 전에 개인별 차감액과 총액을 확인합니다.
3. **입금 기록**에서 선입금을 반영합니다. 기존 입금 내역을 펼쳐 **입금 정정**을 선택하면 대상자·날짜·금액을 고칠 수 있습니다.
4. **월말 검산**에서 계좌와 e바구페이에 보관한 팀 자금을 입력하면 장부 잔액과의 차이를 확인할 수 있습니다. **팀원 관리**에서는 이전 거래를 유지하면서 이름을 수정하거나 활동을 종료할 수 있습니다.

개선판은 브라우저에 예시 장부를 저장하는 독립형 HTML입니다. 비밀번호와 입력 내역은 브라우저별로 관리되며, 실제 팀 정산 기록은 위 운영 장부에서 관리합니다.
