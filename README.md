# 팀 점심 정산

팀원이 관리자 계좌에 미리 입금한 금액에서 개인별 식사비와 커피값을 차감하는 공유 장부입니다.

| 운영 화면 | 사용 방법 |
| --- | --- |
| [팀원 장부](https://vvvis-ai.github.io/lunch-settlement/lunchmenu.html) | 이름과 조회 월을 고르면 이월액, 입금액, 사용액, 잔액을 확인할 수 있습니다. 거래를 펼치면 식사비와 커피값이 표시됩니다. |
| [관리자 장부](https://vvvis-ai.github.io/lunch-settlement/lunchmenu_admin.html) | 기존 관리자 비밀번호로 로그인한 뒤 식사·입금을 기록하고 월말 잔액을 검산합니다. |

## 개선한 점

- **식사 기록**에서 참여자에게 같은 금액을 일괄 적용하거나 개인별로 조정합니다. 매장과 배달 모두 배달비는 무료이며 커피는 마신 사람에게만 추가합니다. 저장 직전에 개인별 차감액과 총액을 확인합니다.
- **입금 정정**으로 날짜·입금자·금액을 수정합니다. **팀원 관리**에서 이름이나 활동 상태를 바꿔도 거래는 유지됩니다.
- **월말 검산**에서 계좌와 e바구페이에 보관한 팀 자금 합계와 장부 잔액의 차이를 확인합니다.

두 운영 화면은 같은 Firebase 장부를 실시간으로 읽습니다. 기존 월별 데이터를 2026년 기록으로 읽고, 첫 저장 시 기존 자료를 보존하면서 개선판 장부를 생성합니다. 이후 두 운영 화면은 개선판 장부를 사용합니다. 관리자 비밀번호는 기존 브라우저 측 로그인 방식이며, 데이터 접근 권한은 Firebase 규칙에서 관리합니다.

[브라우저 전용 예시 장부](https://vvvis-ai.github.io/lunch-settlement/lunch_ledger_v2.html)는 별도로 체험할 수 있습니다.
